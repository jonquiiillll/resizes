# Auto Resize — UXP-плагин для Photoshop

Инструмент для авто-ресайза рекламных PSD-креативов под список целевых
форматов: дублирует документ, меняет холст, раскладывает слои по ролям
(фон/лого/легал/хиро/текст) и сохраняет и PSD, и PNG/JPG на каждый размер.

## Почему именно так устроено

Разобрали реальные примеры ресайзов Сбера (SberSpasibo — 10 форматов,
Вклад — 12 форматов + исходные PSD, GigaChat — 5 рекламных сетей,
"Откройте привилегии" КВ). Вывод: ресайз в проде — это не чистая геометрия,
дизайнер каждый раз слегка пересобирает композицию (перекадровка хиро-фото,
иногда даже переписывает текст). Полностью автоматически один-в-один это не
повторить.

Зато четыре вещи ведут себя предсказуемо во **всех** просмотренных примерах:

- **Фон** — всегда растягивается на весь новый холст.
- **Лого** — всегда в углу, почти не меняет масштаб.
- **Дисклеймер/легал** — всегда прижат к низу, на всю ширину, масштаб под
  минимальный читаемый размер.
- **Хиро-визуал** (фото/3D) — доминирующий элемент, обычно в противоположном
  от текста углу/по диагонали, часто специально вылезает за края канваса.

Плагин автоматизирует эти четыре роли + добавляет эвристику для текстовых
блоков (ставит их в угол, противоположный хиро, масштабирует по площади
холста) и декора (мелкие элементы вокруг хиро — если формат совсем тесный,
декор просто скрывается, чтобы не наезжать на текст).

**Это автопилот, не финальный рендер.** Результат нужно быстро проверить и
где нужно поправить руками (обычно — кроп хиро-фото и перенос строк в
тексте) — как и обсуждали, дизайнер пробегается по сгенерированным PSD.

## Установка (macOS, Photoshop)

1. Установи **Adobe UXP Developer Tool** (UDT) — через Creative Cloud
   Desktop App, вкладка Stock & Marketplace → Plugins → "Get UXP Developer
   Tool", либо напрямую с сайта Adobe Developer.
2. Открой UDT → **Add Plugin** → укажи файл `plugin/manifest.json` из этого
   репозитория.
3. В UDT нажми **Load** напротив плагина (Photoshop должен быть открыт).
4. В Photoshop: **Plugins → Auto Resize** — откроется панель.

Каждый раз после правки кода плагина — жми **Watch** в UDT (авто-релоад при
сохранении файла) или **Reload** вручную.

## Использование

1. Открой исходный PSD в Photoshop, открой панель Auto Resize.
2. В блоке «1. Слои источника» — плагин сам подставит роли по ключевым
   словам в названии слоя (фон/лого/дисклеймер/текст и т.д.), но это только
   догадка — **проверь и поправь** через выпадающие списки у каждого слоя.
   Роль можно назначать как отдельному слою, так и целой группе (группа
   двигается/масштабируется целиком).
3. Отметь нужные размеры из пресетов (Sber КВ, сетка Вклада, IAB/programmatic,
   сторис) или добавь свои через поля W×H.
4. Выбери папку для сохранения результатов.
5. **Сгенерировать все ресайзы** — по каждому размеру появится `WxH.psd` +
   `WxH.png`/`.jpg` в выбранной папке.
6. Открой сгенерированные PSD, поправь то, что автопилот не смог угадать
   (обычно: кроп/поворот хиро-фото, перенос строк в длинном тексте).

## Структура проекта

```
plugin/
  manifest.json     UXP-манифест (панель для Photoshop)
  index.html        разметка панели
  css/styles.css
  js/
    roles.js        роли слоёв + эвристика авто-угадывания по имени
    presets.js       списки целевых размеров (взяты из реальных примеров)
    layerTree.js      обход дерева слоёв по позиционному пути (переживает duplicate())
    engine.js         сама логика ресайза: pin/stretch/cover-fit по ролям
    main.js           UI-обвязка панели
```

## Тюнинг эвристик

Все магические числа (минимальный масштаб лого, порог скрытия декора,
отступы от краёв и т.д.) собраны в объекте `CONFIG` в начале
`plugin/js/engine.js` — трогать в первую очередь там, если авто-раскладка
на конкретном шаблоне выглядит не так.

## Известные ограничения v1

- Не реализован полноценный текстовый reflow (перенос строк по ширине
  paragraph-бокса) — текстовый слой масштабируется целиком как объект, а не
  переверстывается. Для сильно вытянутых форматов (панорама/сторис) переносы
  могут потребовать ручной правки.
- Хиро-кроп — это разумная эвристика (масштаб "cover" + якорь в угол,
  противоположный тексту, с небольшим вылетом за края), а не понимание того,
  что визуально важно на конкретном фото/рендере.
- Код писался и проверялся логически вне Photoshop (эта сессия работает в
  облачной песочнице без установленного Photoshop) — при первом реальном
  запуске возможны мелкие несоответствия UXP API, которые нужно будет
  поправить по консоли ошибок UDT.
